This assistant answers only from a small set of notes about my projects, and every answer links the note it came from. If the answer is not in the notes it says so.

It cannot send or promise anything on my behalf. A request to talk to me waits until I approve it.

It has message and spending limits, and conversations are logged so I can see what people ask.
